
## Overview:

This project demonstrates the development of a real-time analytical dashboard by integrating live data from a public API into Power BI using Python. The objective is to eliminate manual data updates by building an automated data pipeline that continuously fetches, processes, and visualizes global socio-economic and health indicators.

The solution enables decision-makers to monitor key development metrics across countries through dynamic and automatically refreshed dashboards.  


## Problem Statement:

Organizations and analysts often rely on static datasets that quickly become outdated, leading to delayed insights and inefficient decision-making. There is a need for a system that can automatically retrieve continuously updated global data and transform it into actionable insights without manual intervention.


## Tools and skills used:
* Python: pandas, matplotlibs, searborn, REST API Integration.
* Power Bi: dax measures, storytelling visuals


## Approach:

1. Developed a Python-based data pipeline to extract live data from a public API.
2. Performed preprocessing.
3. Established a live connection with Power BI to refreshe dashboard automatically whenever new data becomes available, enabling real-time monitoring and analysis.
4. Interactive visualizations for cross-country comparison.
5. Trend analysis across multiple socio-economic indicator.



## Dashboard Analysis Objectives:

1. Economic and Social Landscape Analysis
* Average GDP per capita across countries.
* Average trade value indicating global market participation.
* Health expenditure as a percentage of GDP.
* Average GDP growth rate.
* Forest area proportion affecting environmental and land-use policies

2. Regional Health Spending Comparison
* Comparison of health spending (% of GDP) across world regions.
* Identification of regional disparities in healthcare investment

3. Socio-Economic Trend Analysis
Analysis of how key indicators change over time:
* GDP.
* Forest area.
* Internet subscriptions.
* Mobile subscriptions.
* Renewable energy usage.
* Unemployment rates

4. Internet Access and Immunization Awareness.
* Evaluation of relationships between internet penetration and immunization rates.
* Assessment of digital connectivity impact on public health awareness.

5. Internet Penetration and Employment
* Analysis of whether increasing internet access contributes to reducing unemployment levels.

6. Poverty Reduction Performance Analysis
* Identification of bottom-performing countries showing the least poverty reduction progress.
* Identification of top-performing countries demonstrating significant poverty reduction.

7. Health Indicator Relationships
 Correlation analysis between:
* Health expenditure.
* Life expectancy.
* Immunization rates.
* Child mortality.
* Disease burden

8. Government Health Spending vs Life Expectancy

*Investigation of the relationship between public health expenditure and life expectancy outcomes.


## Business Impact:

1. Eliminated manual data collection and update processes.
2. Enabled real-time monitoring of global development indicators.
3. Supported data-driven policy and investment analysis.
